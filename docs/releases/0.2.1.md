# PostPlus 0.2.1

Webmail now displays HTML and forwarded messages with decoded Chinese text.
Administration adds external API keys and automatically applies saved settings
by restarting the affected services. Incoming SMTP defaults to TCP port 25.

## Changes

- Mail headers and text bodies convert declared character sets to UTF-8,
  including GB2312, GBK, GB18030 and Big5. Original stored messages and IMAP
  source bytes remain intact. MIME alternatives, related parts and nested
  `message/rfc822` forwards retain the correct body, headers and inline images.
- Webmail and administrator inspection share an HTML reader with tables,
  allowed inline styles, raster CID images and a plain-text switch. HTML is
  sanitized and displayed in a sandboxed frame. Scripts, forms and embedded
  pages are blocked. Remote images require an explicit user action, and that
  permission resets when another message opens. Binary attachment download
  remains unavailable.
- External administration clients can authenticate with
  `Authorization: Bearer <key>` over HTTPS or loopback. The administration
  portal creates keys, displays each complete key once, shows expiry and usage,
  and revokes keys immediately. Only hashes and metadata are stored. Keys have
  full administrator scope; managing keys requires a browser administrator
  session with CSRF protection.
- Saving configuration automatically restarts affected services through the
  native supervisor, including consumers of changed internal endpoints. Restart
  jobs expose pending, running, complete and failed status. Failed application
  restores the previous running configuration while retaining saved settings
  for correction. Standalone services continue to require manual restarts.
- A full restart relaunches through systemd when installed with the updated
  project installer. The unit uses `RestartForceExitStatus=75`; an ordinary
  administration shutdown leaves the service stopped. Windows supervisor state
  reads and atomic replacement tolerate concurrent access without intermittent
  status failures.
- New configurations use SMTP port 25, with deployment guidance for privileged
  ports, inbound firewall rules and existing custom-port installations.

## Upgrade and deployment

Stop PostPlus, back up configuration, data and referenced secrets, then replace
the complete release directory, including its `web` resources. Preserve existing
configuration and data paths. Existing messages display with the new reader
when reopened; they do not need to be received again.

Existing configurations explicitly using `ports.smtp: 2525` keep that value.
For Internet mail reception, change SMTP to 25 and allow inbound TCP 25, or keep
controlled forwarding from public TCP 25 to the configured listener. MX records
cannot specify a port. The systemd installer grants `CAP_NET_BIND_SERVICE`.

For an existing systemd installation, stop `postplus.service`, replace the full
release, and rerun `sudo bash scripts/install-systemd.sh` with the same
configuration path and service account. This updates the unit and enables
automatic full restarts from administration. See the
[Chinese deployment guide](https://github.com/TabNahida/PostPlus/blob/v0.2.1/docs/getting-started.zh-CN.md),
[systemd upgrade guide](https://github.com/TabNahida/PostPlus/blob/v0.2.1/docs/systemd.md)
and [API documentation](https://github.com/TabNahida/PostPlus/blob/v0.2.1/docs/api.md).

## Validation and downloads

The release workflow runs Debug/Release tests on Linux, Windows and macOS,
including SMTP reception, API keys, selective restarts and 13 MIME rendering
fixtures. Each native package is extracted and exercised before publication.
Local Windows/Ubuntu regression and Edge HTML-reader checks also passed.

Verify the downloaded archive against `SHA256SUMS`, extract it, and run
`postplus` (`postplus.exe` on Windows) from the extracted directory.

| Package | Platform |
| --- | --- |
| `postplus-0.2.1-windows-x64.zip` | Windows 10+, x64 |
| `postplus-0.2.1-linux-x86_64.tar.gz` | Ubuntu 24.04 / compatible glibc 2.39+ and GCC 13 C++ runtime, x86_64 |
| `postplus-0.2.1-macosx-arm64.tar.gz` | macOS 15+, Apple Silicon |

Older systems and other architectures can build from source. The macOS package
is unsigned and not notarized.
