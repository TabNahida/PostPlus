## Changes

- Compose plain or formatted mail with file attachments, CC and BCC, replies,
  reply-all and forwarding. Drafts preserve formatting, threading and attachments.
  Download attachments from the message reader with mailbox ownership checks.
- Search decoded subjects, addresses, text and attachment names across folders.
  Filter by sender, recipient, subject, dates, read status and attachments, with
  paginated results. Existing mail is indexed gradually without blocking startup.
- View durable per-recipient delivery status, retry times and event history from
  Sent mail. Local delivery and acceptance by a remote SMTP server are labeled
  separately; remote acceptance does not confirm inbox placement or reading.
- Route incoming spam to Junk and show its score and reasons. Add envelope
  sender/domain allow and block rules, or use an optional local Rspamd service.
  Malware remains quarantined; unavailable scanners defer delivery and retry.
- Improve IMAP and POP3 compatibility with third-party clients: persistent custom
  folders, subscriptions and flags, IMAP IDLE synchronization, SASL PLAIN/LOGIN,
  MIME fetches and folder operations, and exclusive POP3 download transactions.
  Client-created folders appear in Webmail and administration. Fix TLS-buffered
  commands becoming stuck after login or during synchronization.

## Upgrading

PostPlus **0.3.1 and newer** can update directly to this release. The updater
downloads one complete verified package and replaces only changed modules.
Configuration, accounts, mail, queues, certificates and keys remain in place.
Existing messages gain search coverage in batches when searching. Delivery
history is available for new submissions and pending legacy submissions;
completed messages from older versions have no retrospective history.

Installations running **0.3.0** must first install
[0.3.1](https://github.com/TabNahida/PostPlus/releases/tag/v0.3.1) manually.
Keep a private backup before upgrading. Rspamd and ClamAV are optional external
services and are not included in the packages.
