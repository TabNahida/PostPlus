## Changes

- Service restart progress appears only on the Restart and shutdown page.
  Starting or resuming a restart opens that page; completed restart history
  no longer appears throughout administration.
- The settings save toolbar is narrower and centered, with visible space
  around its edges on desktop and mobile screens.
- HTML email images can load when the sender's image host restricts direct
  cross-origin embedding. Image loading preserves the isolated mail renderer
  and validates remote image requests and content.
- Webmail and administration show the message body source without the
  transport headers. Stored messages and full raw-message API responses
  retain their original bytes.

## Upgrading

PostPlus **0.3.1 and newer** can update directly to this release. The updater
downloads one complete verified package and replaces only changed modules.
Configuration, accounts, mail, queues, certificates and keys remain in place.

Installations running **0.3.0** must first install
[0.3.1](https://github.com/TabNahida/PostPlus/releases/tag/v0.3.1) manually.
Keep a private backup before upgrading.
