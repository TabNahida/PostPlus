# PostPlus 1.3.0

PostPlus 1.3.0 adds recent security events directly to administration, schedules
AbuseIPDB protection within conservative free-account budgets, and upgrades the
network backend to PACE 0.4.0 with simpler HTTP and UDP client calls.

## Changes

- **Shorter navigation:** administration uses Overview, Domains, Accounts, Queue,
  Logs, Security, Keys, Settings, Maintenance and Power, with Chinese translations.
- **Recent security events:** opening Security loads the newest 50 failures,
  blocks, policy changes and AbuseIPDB outcomes. Refresh or page through history
  independently of unsaved policy edits. The private database retains 10,000
  events across restarts; the feed requires `security:read` and omits attempted
  account names, credentials, arbitrary notes and raw third-party responses.
  Repeated identical blocked-connection observations are limited to one every
  30 seconds. Recording starts with this update; old service logs are not imported.
- **Automatic blacklist protection:** when AbuseIPDB and automatic blocking are
  enabled, refresh the confidence-100 list every six hours by default. Cache
  membership is checked locally without a network request on connection admission.
  Allowlisted addresses bypass automatic blocking. The minimum report-count rule
  remains specific to individual checks because blacklist entries lack that field.
- **Free-account headroom:** default automatic budgets are four blacklist requests
  and 800 check/report requests per UTC day, counting probes and manual calls.
  Automatic requests also preserve at least 20% of the observed provider allowance.
  Explicit manual tools may use the reserve, subject to provider limits. The
  Security page distinguishes local reservations from observed API usage.
- **Durable request accounting:** local reservations survive restart and key
  replacement. Complete blacklist caches and refresh schedules are isolated by
  credential; small capacity probes cannot replace the enforcement list. Cached
  lists expire after 24 hours, and failed refreshes back off. New individual-check
  caches default to 24 hours; explicitly saved durations are preserved.
- **PACE 0.4.0:** pin the official source archive and license. Internal RPC uses
  `http::async_fetch`; public DNS uses `udp::async_exchange`. Shared deadlines use
  PACE's scoped cancellation, replacing manual socket ownership and timeout code
  while preserving response bounds, DNS validation and application timeout errors.

## Downloads and upgrades

Packages are available for Windows x64, Linux x86_64 and macOS Apple Silicon.
Verify downloads against `SHA256SUMS` from this release before extracting.
See [installation and platform requirements](../releases.md).

PostPlus 0.3.1 and newer can update through **Maintenance → Update PostPlus**.
Existing accounts, mail, configuration, API keys and explicitly saved security
settings are retained. Back up the data directory before updating. Review the
new blacklist option and automatic budgets under **Security → AbuseIPDB**.

See [security events](../security.md), [AbuseIPDB setup](../abuseipdb.md), and
[PACE integration](../pace-migration.md) for behavior and configuration details.
