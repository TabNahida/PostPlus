# PostPlus 1.1.0

PostPlus 1.1.0 refreshes the Webmail and administration interface. This release
changes only the bundled web pages, styles, scripts and icons. Services, APIs,
configuration and stored mail are unchanged and remain compatible with 1.0.1.

## Changes

- **Message list:** each row shows when the message arrived, such as the time,
  "Yesterday", a weekday or a date. Messages are grouped under Today, Yesterday,
  This week and Earlier headings. Opened messages also show a two-line preview
  and a paperclip when they have attachments. Unread messages have an accented
  time and marker.
- **Sender colors:** avatars use one of eight soft colors chosen from the
  sender's address, so different correspondents are easier to tell apart. Quoted
  display names now show their first letter instead of a quotation mark.
- **Loading and empty states:** placeholder rows appear while a folder loads.
  Inbox, Sent, Drafts, Trash, Junk, Archive and search results each have their
  own illustration and wording when empty, in English and Simplified Chinese.
- **Search:** the search bar now spans the top of the mailbox, aligned with the
  list and reader, and has a search icon.
- **Readability:** text sizes now follow a smaller set of steps, and no interface
  text is smaller than 11 px. The font stack uses each platform's system UI font
  with PingFang SC, Microsoft YaHei or Noto Sans CJK SC for Chinese text.
- **Dark mode:** the sidebar, page, panels and cards now have distinct
  lightness levels, and cards have a faint top highlight.
- **Motion:** dialogs, notices, page changes, opened messages and menus fade or
  rise into place in about 0.2 seconds. Cards lift slightly on hover. All
  motion is disabled when the system requests reduced motion.
- **Scrollbars:** scrollbars are thin and follow the light or dark theme,
  including in the sidebar.
- **Administration overview:** statistic cards have icons. The Queued card is
  highlighted when 20 or more messages are waiting, which can point to relay or
  DNS problems. The next-step cards have icons, and **Invite your people** is
  marked complete once the server has more than one account.

## Upgrading

PostPlus **0.3.1 and newer** can update directly to 1.1.0 using **Update
PostPlus**. Service executables are unchanged, so the updater replaces only the
web files. Existing configuration, accounts, mail, queues and certificates are
preserved, and no data migration is required. Follow the
[upgrade guide](https://github.com/TabNahida/PostPlus/blob/v1.1.0/docs/updates.md)
and keep a current backup.

After updating, reload open Webmail and administration tabs so the browser
loads the new styles.
