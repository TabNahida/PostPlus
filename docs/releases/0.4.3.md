## Changes

- Give the manual IP-ban form a compact, responsive layout with aligned IP and
  duration fields, a separate reason row and a stable action footer. Permanent
  mode keeps duration controls visible and disabled to prevent layout shifts.
- Reject banned IPs at public mail and Webmail/administration entrances, before TLS handshakes,
  protocol greetings, HTTP requests or credential processing. The lightweight
  authenticated IP lookup has a bounded deadline and fails closed if auth is
  unavailable. Timed expiry and administrative unban apply immediately.
- Extend real-process coverage across all nine public listeners, including
  implicit TLS, persisted bans, HTTP sessions and incoming SMTP rejection.
- Close expired HTTP input without starting a partial error response, fixing
  a macOS reset race with continuously trickled headers or bodies.

## Upgrading

PostPlus **0.3.1 and newer** can update directly. The updater downloads one
verified complete package and replaces changed modules while preserving
configuration, accounts, mail, queues, certificates and keys.

IP bans now also block incoming SMTP and new Webmail/administration connections
from the same IP, including existing browser logins. Open connections are not
forcibly disconnected. Recover from an unblocked administrator IP or trusted
local RPC; internal services and first-run setup remain available. Review
[IP security](https://github.com/TabNahida/PostPlus/blob/v0.4.3/docs/security.md)
before upgrading, especially when deploying behind a reverse proxy.

Installations running **0.3.0** must first install
[0.3.1](https://github.com/TabNahida/PostPlus/releases/tag/v0.3.1) manually.
Keep a private backup before upgrading.
