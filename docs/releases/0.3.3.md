## Changes

- Release builds reuse successful branch CI for the same commit, avoiding a
  duplicate test matrix. Missing branch checks still trigger the complete
  matrix. Failed or cancelled checks block publication. The SMTP DATA deadline
  regression now tolerates shared-runner scheduling delays while continuing
  to verify a fixed deadline and rejection of incomplete mail.
- Account, forwarding and password-policy sections have consistent spacing.
  Mail forwarding supports exact mailbox addresses and aliases as well as
  wildcard rules. Exact rules can forward existing accounts; wildcard rules
  remain a fallback for unregistered addresses. Destinations are local inboxes,
  and delivery uses one hop to prevent forwarding loops.
- Account deletion has clearer field spacing. Newly generated invitation links
  and their copy controls appear above the invitation history.
- Server settings show an accurate count of unsaved changes in a contained
  save toolbar. DNS expected-value fields provide more room for long records.
  Maintenance and restart/shutdown operations have their own navigation pages.
- Webmail actions and the move menu include icons. HTML mail retains safe
  template styles, alignment and table structure without portal table borders.
  Images load by default; raw MIME remains available after the message body.
- The latest verification-code panel appears only in Inbox and Trash, with
  improved spacing. The API accepts an optional `folder=INBOX` or `folder=Trash`
  to query the corresponding folder; the default remains Inbox.

## Upgrading

PostPlus **0.3.1 and newer** can update directly to this release. The updater
downloads one complete verified package and replaces only changed modules.
Configuration, accounts, mail, queues, certificates and keys remain in place.

GitHub **Latest** now follows the current stable release. Installations still
running **0.3.0** must first install
[0.3.1](https://github.com/TabNahida/PostPlus/releases/tag/v0.3.1) manually, then
use its updater. Keep a private backup before upgrading.
