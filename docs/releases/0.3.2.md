## Changes

- Removes legacy per-module update downloads. Online updates use one verified
  complete package, then stage and replace only changed allowlisted modules.
  Unchanged modules, configuration, accounts, mail, queues, certificates and
  private keys stay in place. Only affected services restart; launcher changes
  restart the service group.
- Releases contain eight assets: three complete packages, three platform
  metadata files, the combined update manifest and SHA256SUMS. Individual
  `.module` assets are no longer published.
- Includes all administration improvements from 0.3.1: searchable paginated
  service logs, a separate DNS recommendation and server connectivity panel,
  searchable and collapsible accounts with deletion, an invitation dialog
  beside Create user, and a collapsed forwarding-rules table.
- Downloads precede Changes in English release notes, with direct links on
  each package filename.

## Upgrading

Existing **0.3.0** installations must first update to
[0.3.1](https://github.com/TabNahida/PostPlus/releases/tag/v0.3.1), then check
again and update to 0.3.2. **0.3.1** can update directly to this release.
New installations can download the appropriate 0.3.2 package above.

GitHub's **Latest** pointer deliberately remains on 0.3.1 for unmodified
0.3.0 clients. PostPlus 0.3.1 and newer find the highest stable release by
version, so they still discover 0.3.2 automatically. Keep a backup before
upgrading. DNS connection checks originate on the server and do not prove
external inbound reachability or successful mail delivery.
