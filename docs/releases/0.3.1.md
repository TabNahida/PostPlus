## Changes

- Service logs support text search and **Load more**, including retained rotated
  logs. Pagination keeps a snapshot while new events arrive.
- Server settings separate **DNS** from **Network**. DNS lists recommended mail
  and client-discovery records, including configured records, and checks public
  DNS and configured service connections from the server. Checks can run after
  editing records at your DNS provider without saving server settings.
- User accounts have search, a table expanded by default, and account deletion.
  Deletion revokes credentials and removes mailbox data; self-deletion is blocked.
  Mailbox invitations open from a button beside **Create user**. Forwarding rules
  use a table in a section collapsed by default.
- The updater can download one verified complete package and replace only changed
  modules. Unchanged modules, configuration, accounts, mail, certificates and
  private keys remain in place. Affected services restart when applying changes.
- This transition release also publishes and accepts the legacy module format
  needed by 0.3.0. Later releases use complete packages only.

## Upgrading

Install 0.3.1 through the 0.3.0 administration updater, then check again to find
0.3.2 or a newer stable release. New installations can use the newest full
package directly. Keep a backup before upgrading.

The GitHub **Latest** pointer remains on this compatibility release so existing
0.3.0 installations can find their bridge. Starting with 0.3.1, PostPlus selects
the highest stable version from GitHub Releases, independently of that pointer.
Connection checks originate on your server and do not prove that every external
network can connect; verify firewall and provider restrictions separately.
