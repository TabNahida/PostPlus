# PostPlus 1.2.1

PostPlus 1.2.1 improves the Security page, separates AbuseIPDB credentials from
other settings, and discovers available API capacities after saving a key.

## Changes

- **Security navigation:** rename Login security to Security in English and
  Simplified Chinese, covering both local protection and AbuseIPDB controls.
- **Time units:** choose seconds, minutes, hours or days for reputation blocks,
  cache duration and reporting cooldowns. Report lookback accepts days or weeks.
  Unit changes preserve the exact stored value; fractional seconds or days and
  values outside the displayed limits are rejected.
- **Independent cards:** the API key, Webmaster token and security policy have
  separate save actions. A saved key displays its configured status; choose
  Modify API key to edit it. Cancel clears the draft. Saving a token or policy
  preserves credentials and unrelated unsaved fields.
- **Capacity discovery:** saving a key automatically probes the four read
  endpoints: check, reports, blacklist and check-block. A separate Refresh
  capacity action repeats discovery, with a 60-second cooldown and bounded
  request budgets. Each probe consumes that endpoint's request allowance.
- **Accurate quota state:** limits come from actual response headers. Report,
  bulk-report and clear-address capacities remain Unknown until a real
  operation returns them; discovery never submits or removes reports. Partial
  results and failures appear separately from successful credential saving.
- **Credential isolation:** saved secrets are not returned to the browser,
  responses for a replaced key do not update its successor's quota state, and
  rate-limit backoff remains effective during concurrent requests. Policy and
  Webmaster updates preserve observed capacities.

See [AbuseIPDB setup](../abuseipdb.md) for key sources, capacity discovery and
Webmaster verification.

## Downloads and upgrades

Packages are available for Windows x64, Linux x86_64 and macOS Apple Silicon.
Verify downloads against `SHA256SUMS` from this release before extracting.
See [installation and platform requirements](../releases.md).

PostPlus 0.3.1 and newer can update from **Server maintenance → Update PostPlus**.
Existing accounts, mail, configuration and AbuseIPDB settings are retained.
Back up the data directory before updating. Open **Security → AbuseIPDB** to
review the revised controls; no API key replacement is required for the upgrade.
