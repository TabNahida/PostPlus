## Changes

- Choose seconds, minutes, hours or days for login-protection durations. Existing
  policy values and the default protection thresholds remain unchanged.
- Add permanent manual IP bans alongside timed bans. Permanent bans survive
  restarts, appear clearly in the ban pool and remain until an administrator
  unblocks the address. The administration API also supports permanent bans.
- Show more service-log rows with a taller, responsive table and tighter row
  spacing while retaining search, filters, sticky headers and pagination.

## Upgrading

PostPlus **0.3.1 and newer** can update directly. The updater downloads one
verified complete package and replaces changed modules while preserving
configuration, accounts, mail, queues, certificates and keys. Existing timed
bans retain their expiry; automatic protection remains temporary. Review
[login security](https://github.com/TabNahida/PostPlus/blob/v0.4.2/docs/security.md)
for the permanent-ban API and administrator recovery options.

Installations running **0.3.0** must first install
[0.3.1](https://github.com/TabNahida/PostPlus/releases/tag/v0.3.1) manually.
Keep a private backup before upgrading.
