## Changes

- Record source IP, protocol, account and outcome for password and API-key
  authentication without logging credentials. Add shared, persistent temporary
  IP bans for repeated nonexistent-account attempts and authentication failures
  across Webmail, administration, SMTP, IMAP and POP3 connections.
  Defaults: five nonexistent-account failures or twenty total failures within
  five minutes temporarily block authentication for fifteen minutes.
- Add an administration Security page with immediate policy changes, IP/CIDR
  allowlisting, a searchable ban pool and manual ban/unban controls. Separate
  API-key permissions govern security viewing and management. Existing browser
  sessions remain available for recovery.
- Fix IMAP multipart BODYSTRUCTURE grammar, non-ASCII metadata strings and
  address parsing. Retrieve metadata independently of attachment decoding;
  avoid false size-limit failures for large forwarded messages. Preserve exact
  MIME sections and partial-download bytes for third-party mail clients.
- Make POP3 LIST/STAT sizes match the downloaded CRLF message, including imported
  messages with LF-only or unfinished final lines. Cache metadata and populate
  existing maildrops on demand while preserving stored mail.
- Place verification codes and the shorter mail search field side by side on
  desktop, with responsive stacking on narrow screens.

## Upgrading

PostPlus **0.3.1 and newer** can update directly. The updater downloads one
verified complete package and replaces changed modules while preserving
configuration, accounts, mail, queues, certificates and keys. Existing API keys
keep their permissions; grant `security:read` or `security:write` explicitly
when needed. Login protection is enabled by default. Review
[login security](https://github.com/TabNahida/PostPlus/blob/v0.4.1/docs/security.md)
when placing PostPlus behind a proxy, since the trusted source is the TCP peer.

Installations running **0.3.0** must first install
[0.3.1](https://github.com/TabNahida/PostPlus/releases/tag/v0.3.1) manually.
Keep a private backup before upgrading.
