# PostPlus 1.2.0

PostPlus 1.2.0 adds manual DNS review, server-side public IP discovery,
AbuseIPDB reputation tools and security automation, and upgrades PACE to 0.2.0.

## Changes

- **DNS review:** mark a domain as checked after reviewing its DNS manually.
  Manual acknowledgements are saved with a timestamp and remain distinguishable
  from resolver verification. Relevant configuration changes and expiry still
  require a fresh review.
- **Public IP defaults:** the server queries fixed public HTTPS services for
  IPv4/IPv6 expectations when they are not provided. Explicit IP values are
  retained. Discovery is bounded and cached; unavailable families can still be
  entered manually.
- **AbuseIPDB:** configure an API key, inspect observed usage and capacity, and
  use check, reports, blacklist, check-block, report, bulk-report and
  clear-address. Bulk checks use individual check calls and their quota.
- **Security policies:** optionally block source IPs using abuse confidence
  and report counts, or report repeated locally observed failed sign-ins.
  Policies respect allowlists, cache checks and apply per-IP report cooldowns.
- **Webmaster verification:** publish your AbuseIPDB verification token at
  `/abuseipdb-verification.html` from administration, then complete verification
  on AbuseIPDB.
- **Networking:** PACE 0.2.0 is pinned through a bundled recipe with a verified
  source archive digest. TLS, DNS and HTTP/1 remain enabled with static OpenSSL.

See [AbuseIPDB setup](../abuseipdb.md) and [build dependencies](../build-dependencies.md).

## Downloads and upgrades

Packages are available for Windows x64, Linux x86_64 and macOS Apple Silicon.
Verify them against `SHA256SUMS` from this release before extracting.
See [installation and platform requirements](../releases.md).

PostPlus 0.3.1 and newer can update from **Server maintenance → Update PostPlus**.
Configuration, mail and accounts are preserved. Back up the data directory
before updating. New AbuseIPDB settings are stored in the authentication
database; automatic reputation actions remain off until explicitly enabled.
