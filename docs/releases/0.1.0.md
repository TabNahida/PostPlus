# PostPlus 0.1.0

PostPlus brings browser-based setup, server administration, and Webmail to a
native mail server for Windows, Linux, and macOS.

## Getting started

Download the archive for your system, verify it with `SHA256SUMS`, extract it,
and run `postplus` (`postplus.exe` on Windows) from the extracted folder. Open
the setup address printed in the terminal and enter the one-time password.
No compiler or Python installation is needed.

| Package | Platform |
| --- | --- |
| `postplus-0.1.0-windows-x64.zip` | Windows 10+, x64 |
| `postplus-0.1.0-linux-x86_64.tar.gz` | Ubuntu 24.04 / glibc 2.39+, x86_64 |
| `postplus-0.1.0-macosx-arm64.tar.gz` | macOS 15+, Apple Silicon |

The macOS package is unsigned and not notarized. See the bundled
`docs/releases.md` for installation, checksum verification, and platform details.

## Included

- First-run web setup and a native supervisor for all service processes.
- Separate administration and Webmail pages, with English/Chinese, light/dark
  appearance, system theme matching, and mobile layouts.
- Account administration, individual quotas, account password rules, mailbox
  inspection, service logs, data backups, and server shutdown controls.
- Inbox, Sent, Drafts, Trash, Junk, and Archive, with plain-text composition.
- SMTP, POP3, a documented IMAP subset, MIME parsing, and TLS support.
- Local delivery and outbound mail through a configured SMTP relay.
- Let's Encrypt HTTP-01 certificate requests, spam rules, EICAR detection, and
  integration with an external ClamAV service.
- SQLite-backed accounts, mailboxes, delivery queues, and retries.

## Current scope

This is the first release. Full IMAP compatibility, attachments in Webmail,
direct MX delivery, SPF/DKIM/DMARC, automatic certificate renewal, OS service
installation, and multi-host operation are not implemented. Consult the bundled
README and protocol documentation before an internet-facing installation.

Saved server configuration takes effect after a manual restart. Existing
installations retain their configured password policy; new installations default
to an eight-character minimum. Size and user-count capacity should be validated
with a workload representative of your installation.
