Copy the one-time setup password from the terminal running PostPlus.

Server identity

Use the part after @ in your email addresses. For example, example.com.

PostPlus stores mail, accounts, and service logs in this folder.

First administrator

Use an address on the mail domain above.

At least 12 characters.

Connections and security

Local mode listens on this computer only. Choose TLS to allow network access.

127.0.0.1 is local only. Use 0.0.0.0 to listen on all IPv4 interfaces.

Enter paths to existing PEM files on the server. The private key must be readable by PostPlus.

Service ports
Adjust service ports

Administration and Webmail have separate addresses. Administration defaults to port 8081; Webmail defaults to 8080.

Defaults avoid privileged ports. Use different ports for each service.

Optional services
Outgoing mail relay

A relay (smarthost) sends mail to other domains. Leave blank for local mail only.

Set this environment variable before starting PostPlus. Do not enter the relay password here.

ClamAV antivirus

Connect an existing ClamAV daemon. Leave the host blank to skip antivirus integration.

Defaults work for a first local mailbox. You can change these options later in administration.
