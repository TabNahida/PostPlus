Publish and check your DNS
Connections and security

Local mode listens on this computer only. Choose TLS to allow network access.

127.0.0.1 is local only. Use 0.0.0.0 to listen on all IPv4 interfaces.

Use PEM files already on your server, including certificates obtained with DNS-01 or another client. This method does not require public port 80.

Built-in HTTP-01 requires public DNS for the server hostname and inbound TCP port 80. Start with staging, then request a production certificate.

Enter paths to existing PEM files on the server. The private key must be readable by PostPlus.

Service ports

Public defaults are SMTP 25, POP3 110, IMAP 143, and Webmail 80 (443 with TLS). On Unix, grant PostPlus permission to bind privileged ports.

Legacy port values detected. Apply standard ports and save to switch to public defaults.

Existing custom ports stay unchanged until you apply this preset and save.

Adjust service ports

Administration and Webmail have separate addresses. Administration defaults to port 8081; Webmail uses the mail server hostname.

Use different ports for each service. A custom SMTP port requires forwarding from public TCP 25.

Dedicated secure client ports are submission 587, SMTPS 465, POP3S 995, and IMAPS 993. Set a dedicated port to 0 to disable it; it requires both TLS files to start.
